# API 接口文档

## 文档概述

本文档提供了AI笑话管理系统的完整API接口规范。系统采用RESTful设计原则，支持JWT Token认证和细粒度权限控制。

1. 用户及权限

- root用户：具有最高权限，可以创建主题、创建其他用户、配置主题管理员，拥有如下角色的所有功能。
- 普通用户：具有对各个主题笑话的浏览、点赞、投稿、搜索权限，以及对主题的评论权限。根据权限表，如果用户还具有某个主题的特定权限（管理员），包含笑话增删改、评分，配置其他用户对主题的权限，则允许进行对应的操作。这里的增，还包含对用户投稿的审批。

本次您只需要设计简单的鉴权。

2. 主题系统

主题仅可由root用户创建，包含：评论区、笑话两部分。

3. 笑话系统

笑话包含：标题（非必需）、内容、AI评分、人工评分、最终评分（优先取人工评分，若无取AI评分，若无则为默认值7）创建时间、修改时间、作者、所属主题、状态（展示/审核/不展示）等等。
对笑话进行增加时，会先查看该主题的笑话数据库有没有相似度＞95%的笑话，如果有，则弹出提示，要求二次确认。

4. 评论系统

用户可以对主题进行评论。

## 评分说明

| 分数基准 | 描述 |
|----------|------|
| 10分 | 非常优秀的笑话，有很强的创意和笑点 |
| 8分 | 优秀的笑话，有明显笑点 |
| 6分 | 一般的笑话，无法让用户笑起来 |
| 4分 | 偏离主题，不知所云，或没有笑点的笑话 |
| 2分 | 和主题有一部分相关性，但不算笑话 |
| 0分 | 无关内容，不是笑话 |

### 高质量笑话示例
- ✅ 改编经典文学作品、影视台词的笑话
- ✅ 包含游戏内梗和网络梗的内容
- ✅ 涉及谐音梗、创新的冷笑话
- ✅ 包含情感表达和情绪变化的笑话

### 低质量内容示例
- ❌ "鸡煲又死了"（纯游戏状况描述）
- ❌ "鸡煲好强啊"（简单情绪表达）
- ❌ "这个视频真好看"（普通观赏评论）


## 基础配置

- **Base URL**: `http://localhost:8080`
- **认证方式**: JWT Token（Header: `Authorization: Bearer <token>`）
- **内容类型**: `application/json`
- **字符编码**: `UTF-8`

> **注意**: 本项目采用RESTful资源为中心的设计，使用HTTP方法表示操作，路由使用名词表示资源。

### 统一响应格式

#### 成功响应
```json
{
  "success": true,
  "code": 200,
  "message": "操作成功",
  "data": {
    // 具体数据
  },
  "timestamp": "2024-01-01T00:00:00Z",
  "requestId": "uuid"
}
```

#### 分页响应
```json
{
  "success": true,
  "code": 200,
  "message": "查询成功",
  "data": {
    "content": [], // 数据列表
    "page": 0,      // 当前页码
    "size": 10,     // 每页大小
    "totalElements": 100, // 总记录数
    "totalPages": 10,     // 总页数
    "first": true,        // 是否首页
    "last": false,        // 是否末页
    "empty": false        // 是否为空
  },
  "timestamp": "2024-01-01T00:00:00Z",
  "requestId": "uuid"
}
```

#### 错误响应
```json
{
  "success": false,
  "code": 400,
  "message": "请求参数错误",
  "error": {
    "type": "VALIDATION_ERROR",
    "details": [
      {
        "field": "username",
        "message": "用户名不能为空"
      }
    ]
  },
  "timestamp": "2024-01-01T00:00:00Z",
  "requestId": "uuid"
}
```

### 通用请求参数

#### 分页参数
- `page`: 页码（从0开始），默认0
- `size`: 每页大小，默认10，最大100
- `sort`: 排序字段，默认按创建时间
- `order`: 排序方向，`asc`或`desc`，默认`desc`

#### 时间范围参数
- `timeRange`: 时间范围，可选值：`day`、`week`、`month`、`quarter`、`year`
- `startDate`: 开始日期（ISO 8601格式）
- `endDate`: 结束日期（ISO 8601格式）

## 权限体系

### 用户角色
- **ROOT**: 系统最高权限，可以管理所有资源
- **USER**: 普通用户，可以浏览、投稿、评论，也可能存在主题管理权限。

### 主题管理权限级别
- **write**: 新增笑话，审批、评分、删除笑话权限
- **admin**: 管理权限，可以对其他用户赋予上面的权限
